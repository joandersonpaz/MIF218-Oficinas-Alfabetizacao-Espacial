# MIF218 - Oficinas sobre Alfabetização Espacial

Bem-vindo(a) ao repositório do projeto de extensão desenvolvido para o Módulo Interdisciplinar de Formação (MIF218) da UFOP!

O objetivo deste projeto é apoiar professores de Matemática e Geografia na alfabetização espacial dos alunos dos Anos Finais (6º e 7º anos), utilizando ferramentas digitais interativas desenvolvidas em Python.

## Guia Didático para o Professor
Para aprender a usar os softwares em sala de aula, baixe o nosso guia passo a passo:

[Clique aqui para baixar o Guia Didático em PDF](https://github.com/joandersonpaz/MIF218-Oficinas-Alfabetizacao-Espacial/blob/main/Guia%20Did%C3%A1tico%20Pr%C3%A1tico%20%E2%80%93%20Oficinas%20de%20Alfabetiza%C3%A7%C3%A3o%20Espacial%20-%20Joanderson%20Paz.pdf)

## Organização do Repositório
*   **Pasta `Executaveis`:** Contém os arquivos `.exe` prontos. Basta baixar e dar dois cliques para usar (não precisa instalar nada).
*   **Pasta `Python`:** Contém os códigos-fonte (`.py`) para quem quiser estudar ou modificar os softwares.

## Os Softwares
1. **Robô Cartógrafo:** Coordenadas cartesianas, lateralidade e algoritmos.
2. **Laboratório de Transformações:** Escalas, rotações e isometrias.
3. **Do 3D para o 2D:** Construção de relevo e mapas topográficos.
4. **GeoCenso:** Coleta de dados e geração de gráficos estatísticos.
